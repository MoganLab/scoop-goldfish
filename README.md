# scoop-goldfish

Scoop bucket for [Goldfish Scheme](https://github.com/MoganLab/goldfish).

## 安装与使用

### 1. 添加此 Bucket

```powershell
scoop bucket add goldfish https://github.com/MoganLab/scoop-goldfish.git
```

### 2. 安装 Goldfish

```powershell
scoop install goldfish
```

安装完成后，可以在命令行中使用 `gf` 或 `goldfish` 命令：

```powershell
gf --version
```

### 3. 更新 Goldfish

```powershell
scoop update
scoop update goldfish
```
